# Development modules

This directory is limited to temporary Bdev-owned operation-pack prototypes and
small integration fixtures. It must not contain copied scWorkbench core or
vendored official operation-pack source.

Paper-facing reusable methods should be implemented on branches in the owning
upstream repositories. Before implementation begins, prototypes must either be
promoted to an official pack and included in the qualified SIF or be explicitly
classified as approved outside preprocessing.
