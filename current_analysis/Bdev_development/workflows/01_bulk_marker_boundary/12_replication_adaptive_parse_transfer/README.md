# Replication-adaptive Parse transfer

This step preserves the completed three-fold Parse-transfer sets for targets
with at least three independent ImmGen units. It extends construction to the
remaining targets using two leave-one-unit-out top-100 rankings when two units
exist and a full-data top-100 ranking when only one unit exists.

Evidence tiers remain explicit. Singleton sets are provisional and cannot gain
a reproducibility claim from full-data separation. All construction uses
ImmGen only; single-cell expression is reserved for later evaluation after a
method and memberships are frozen.
