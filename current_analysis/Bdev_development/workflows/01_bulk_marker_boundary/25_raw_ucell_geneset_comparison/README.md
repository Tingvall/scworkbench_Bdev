# Raw-UCell comparison of supplied and generated narrow gene sets

This diagnostic comparison runs the native scWorkbench argmax reducer directly
on raw UCell scores with a 0.01 raw-score margin. It compares the 47 supplied,
equal-size sets with the preceding 64 ImmGen-generated population-specific
local modules. Percentile calibration and generated lineage-anchor modules are
excluded. No artifacts or labels are promoted.
