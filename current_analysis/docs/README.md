# Documentation

This directory will document how selected exploratory analyses are recreated
with the updated scworkbench module framework.

For each selected step, capture:

- the scientific question and intended output;
- archived source artifacts and their exact paths;
- the legacy operations used, when recoverable;
- the corresponding default module(s) in the updated framework;
- any missing capability that requires a custom module;
- parameter, metadata, and identifier mappings;
- validation criteria and expected differences from the exploratory result.

The selection of steps and the new scworkbench interface are pending.
